# Audio Pedal
I want to create a hardware project for audio filtering and modification, much like a very capable guitar pedal. But first, I'm going to start by doing all of this work in MATLAB before going to an FPGA or something, just so that my debug and iterations are quicker.

## Structure
We have many components that all can be combined into a comprehensive combination of different effects.

### The Effects Component
On the left side of the panel there are many effects you can mess with.

### The Spectrum
On the right there is a spectrum so that the user can see what is actually happening to the signal.
